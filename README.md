# Mokshit Sai Sreeram — Developer Portfolio

## Run locally
1. Install Node.js LTS: https://nodejs.org/
2. Extract this folder and open it in VS Code.
3. In the terminal run `npm install`, then `npm run dev`.
4. Open the localhost URL printed by Vite (usually http://localhost:5173).

## Deploy
Push this project to a public GitHub repository, then import it at https://vercel.com/new.
Choose Vite, build command `npm run build`, output directory `dist`.
